# Settings field maps

Extracted from the game's own reflection data in `Need For Speed The Run.exe`, not guessed.
Each settings class has a `?c_TypeInfoData@<Class>@fb@@` record in the `typeinfo` segment:

    +0x00  const char*  class name
    +0x04  u16          field count
    +0x18  FieldInfo*   field array

and each field entry is 12 bytes:

    +0x00  const char*  name
    +0x04  u16          flags
    +0x06  u16          OFFSET within the object
    +0x08  TypeInfo*    type

Type pointers seen: `02A95E38` = bool, `02A95E88` = int32, `02A95E98` = enum/int,
`02A95EC8` = float, `02760A68`/`02760AA0`/`02760AD0` = vector types.

Verified: every `GameRenderSettings` offset here matches what was read live in ReClass,
and `EmitterSystemSettings.Enable` at `0x62` matches the game's own debug print
("EmitterSystem.Enable", offset 98).

CAVEAT: the field count is read from the record and a few classes list entries whose
offsets repeat. Those are almost certainly fields of nested structs being flattened, so
treat any duplicate offset with suspicion and confirm it live before relying on it.
